Welcome to DWEEB_DOS! This is a lightly customized version of DOSBOX STAGING,
tweaked by me, TechDweeb, for you to enjoy. I do it to spread my love of DOS
to all the little DOS noob dweebs of the world. Like you.

CUSTOMIZATIONS INCLUDE:
- CRT Shader (can be changed or disabled by editing the glshader line at 
	the top of dosbox-staging.conf)
- Dos Navigator (file manager, accessible by entering 'dn')
- Text editor (accessible by entering 'edit', or 'edit FILENAME')
- Colourized DOS prompt (Turn off with 'dwbnofun', or turn on with 'dwbfun')

COMMON DOS COMMANDS:
- dwb  <- Takes you back to the DWEEB_DOS homescreen
- help  <- Nice easy help info for common DOS commands
- intro  <- Simple tutorial explaining mounting commands and hotkeys
- exit  <- exits DOS
- dir/w  <- Directory listing in wide format. Add /p to enable page view.
- cd DIRECTORY  <- Change to a directory (ex cd duke3d will go to c:\duke3d)
- cd ..  <- Navigates BACK to a previous directory
- cd\  <- Naivgates to the root level of the current drive
- d:  <- Navigates to the D: drive (if you have a CD mounted, for instance)
- imgmount d IMAGENAME.IMG -t -cdrom  <- Mounts the image as the D: drive
- mount /u d  <- Unmounts the image mounted as the D: drive
- ADVANCED COMMANDS: md (make directory), move (move file or directory),
	('move' also for renaming directories), rd (remove directory),
	del (delete file(s)), cls (clear DOS screen)

DOSBOX HOTKEYS:
- ALT+F4  <- Quick exit DOS
- CTRL+F12  <- Increase emulated CPU clock
- CTRL+F11  <- Decrease emulated CPU clock

PRO TIP: 
- Create a shortcut for dosbox.exe in Windows (ex, on your desktop), and
	edit the properties to assign a shortcut key (ex, CTRL+ALT+SHIFT+F12)
	to allow you to easily enter DOS from anywhere in Windows!
